# सुरक्षित गेट (Surakshit Gate)

स्कूल के बच्चों का QR आईडी कार्ड, गेट पर फोन से स्कैन, माँ-बाप को आने/जाने का मैसेज, और **माँ-बाप की “हाँ” + OTP** के बिना किसी और को बच्चा न सौंपने वाला पिकअप सिस्टम। मोबाइल ब्राउज़र में ऐप की तरह चलता है (Android + iPhone), हिंदी में, कोई ऐप डाउनलोड नहीं।

> सारा डेमो डेटा नकली है (नाम, नंबर `90000xxxxx`, फोटो)। असली डेटा सिर्फ़ मालिक के लिखित कहने पर।

## कौन क्या करता है

| भूमिका | लॉगिन | क्या दिखता है |
|---|---|---|
| गार्ड | हाँ | सिर्फ़ गेट स्कैनर और पिकअप (रिपोर्ट नहीं) |
| क्लास टीचर | हाँ | सिर्फ़ अपनी क्लास: परेड गिनती, बच्चों की हाज़िरी |
| प्रिंसिपल | हाँ | आज/महीने की रिपोर्ट, पिकअप रिकॉर्ड, अलर्ट, बच्चे, कार्ड, ऑफिस बैकअप |
| एडमिन | हाँ | सब कुछ + लॉगिन बनाना/बंद करना, सेटिंग, नया सत्र, बैकअप/रिस्टोर |
| माँ-बाप | नहीं | हर पिकअप का अलग सुरक्षित लिंक (कुछ मिनट में खत्म) |

## मुख्य काम

- **बच्चे:** नाम, क्लास, रोल, फोटो (कैमरा या गैलरी), माँ-बाप का मोबाइल। जोड़ना/बदलना/हटाना, Excel→CSV से एक साथ जोड़ना (पहले जाँच, फिर जोड़ना)।
- **QR कार्ड:** हर बच्चे का रैंडम QR (`SG1.<टोकन>`, नाम/नंबर नहीं, अंदाज़ा नहीं लग सकता)। A4 पर 10 कार्ड की PDF (फोटो, नाम, क्लास, QR)। कार्ड खोया → पुराना QR उसी समय बंद, नया बनता है; पुराना स्कैन हो तो गार्ड को लाल चेतावनी + एडमिन को अलर्ट।
- **गेट:** लगातार चलने वाला स्कैनर (Android में फोन का BarcodeDetector, iPhone में jsQR) — स्कैन पर बड़ी फोटो, नाम, क्लास। पहला स्कैन = “आया” + मैसेज। छुट्टी में दोबारा स्कैन → “बच्चा निकला (माँ-बाप के साथ)” / “कोई और लेने आया है”। मैसेज की स्थिति ✓ भेजा / ✓✓ पहुँचा / ✓✓ देख लिया / ✕ नहीं पहुँचा।
- **पिकअप:** लेने वाले की फोटो + नाम/रिश्ता → माँ-बाप को फोटो, नाम, OTP और “क्या बच्चे को भेजना है?” का लिंक। बच्चा **तभी** सौंपा जाता है जब माँ-बाप ने “हाँ” कहा हो **और** OTP सही हो। “नहीं” → गार्ड को लाल चेतावनी, OTP का खाना हटता है। गलत OTP → अलर्ट + गिनती (5 बार पर पिकअप बंद)। OTP हर पिकअप का अलग, रैंडम, 5–10 मिनट, एक ही बार। जवाब न आए → ऑफिस बैकअप (प्रिंसिपल फोन करके “फोन पर हाँ/मना” दर्ज करता है)। गार्ड को OTP कभी नहीं दिखता।
- **रिकॉर्ड और रिपोर्ट:** हर पिकअप (मना किए भी) — किसने लिया, फोटो, OTP भेजने/देखने/हाँ/निकलने का समय, गलत कोशिशें। आज की गिनती, क्लास-वार, गैरहाज़िर सूची, परेड मिलान (हरा/लाल + कितना फर्क), महीने की हाज़िरी (CSV डाउनलोड)।
- **एडमिन:** लॉगिन बनाना/बंद करना, नया सत्र (क्लास आगे बढ़ाना, पास-आउट हटाना — पहले अपने आप बैकअप), सेटिंग, बदलाव का रिकॉर्ड।
- **सुरक्षा:** HTTPS, पासवर्ड bcrypt hash, 5 गलत लॉगिन पर 15 मिनट लॉक + rate limit, भूमिका के हिसाब से API पर रोक, httpOnly session cookie + CSRF header, NoSQL-injection रोक, फोटो सिर्फ़ लॉगिन/सही लिंक से, OTP सिर्फ़ माँ-बाप के लिंक से खुलता है (लिंक टोकन से encrypted)।
- **डेटा:** रोज़ अपने आप बैकअप (14 रखे जाते हैं) + एडमिन पेज से रिस्टोर; लेने वालों की फोटो N दिन बाद अपने आप मिटती हैं (सेटिंग में, डिफ़ॉल्ट 30)।

## मैसेज

`MESSAGE_PROVIDER=demo` (डिफ़ॉल्ट): असली SMS/WhatsApp नहीं जाते; एडमिन/प्रिंसिपल के “मैसेज → डेमो: माँ-बाप का फोन” में दिखते हैं, लिंक वहीं से खुलता है। `0000` पर खत्म होने वाला नंबर “बंद नंबर” जैसा व्यवहार करता है (अलर्ट का डेमो)।
असली के लिए: `MESSAGE_PROVIDER=whatsapp` — देखें [docs/WHATSAPP-SETUP.md](docs/WHATSAPP-SETUP.md)।

## डिप्लॉय (VPS, एक कमांड)

```bash
curl -fsSL https://raw.githubusercontent.com/ganeshrprajapati29/Qr-code-demo/main/surakshit-gate/deploy/install.sh | bash
```

- लिंक: `https://gate.<VPS-IP-डैश-से>.sslip.io` (अपना डोमेन हो तो `DOMAIN=gate.school.in` आगे लगाएँ)
- पहले लॉगिन के पासवर्ड आख़िर में छपते हैं (`/opt/surakshit-gate/shared/first-logins.txt`)
- सब कुछ `/opt/surakshit-gate` में: अपना Node.js, अपना MongoDB (`127.0.0.1:27028`), अपनी systemd सर्विस; nginx में सिर्फ़ एक नई फ़ाइल — सर्वर के बाकी प्रोजेक्ट पर असर नहीं।
- **प्राइवेट repo:** `curl -fsSL -H "Authorization: token <TOKEN>" <raw-url> | GITHUB_TOKEN=<TOKEN> REPO_URL=https://github.com/<owner>/<repo>.git bash` (टोकन सर्वर पर सेव नहीं होता)
- अपडेट: वही कमांड दोबारा। हटाना: `bash /opt/surakshit-gate/app/deploy/uninstall.sh`

## लोकल पर चलाना / टेस्ट

```bash
cd server && npm install && SEED_PASSWORD=demo12345 npm run seed && npm run dev     # API :5070
cd client && npm install && npm run dev                                              # http://localhost:5173
cd server && npm test    # 13 टेस्ट: स्वीकृति सूची के सारे नियम, असली MongoDB पर
```

**टेक:** Node.js 22 + Express 5, MongoDB 8 (Mongoose), React 19 + Vite (PWA), nginx + Let's Encrypt।
